# Dog-facts
A simple and fun web app that shows dogs facts using the public Dog API.

# Node.js & Express API Server
A lightweight, robust RESTful API built with Node.js and Express.

## 📦 Installation
Follow these steps to set up the project locally:
1. **Clone the repository:** <br>
   git clone https://github.com/Sri-amxn/Dog-facts.git<br>cd DOG FACTS
   
3. **Install dependencies:**<br>
   npm i or npm install (this will install the node modules folder.)

## 🏃‍♂️ Available Scripts

In the project directory, you can run:

### `nodemon index.js`
Runs the app in development mode using `nodemon` (auto-reloads on file changes).
